## 1. 总体结论

课程管理、文档入库、课程 RAG、多轮对话、练习生成、自动批改、掌握度和学习计划的后端主链路已经运行。统一聊天入口已增加意图路由，Practice Agent 也已可在对话中创建可批改练习。

主要差距集中在五类：前端操作不完整、RAG 质量工程未完成、学术诚信未实现、用户画像与反馈闭环不完整、评测与可观测性不足。

## 3. 与原设计的明确偏离

1. 技术设计预期 Vue 3 + Vite，当前为 FastAPI 托管的原生 HTML/CSS/JavaScript。对本地 MVP 有利，但需在技术文档中正式记录变更。
2. 设计中 Worker 使用 Redis 队列，当前 Worker 轮询 PostgreSQL jobs。
3. 设计中 Agent 通过工具层访问 RAG/业务数据，当前 Service 直接组合 Repository 和 Retriever。
4. 设计中教学 Skill 替换客服 Skill，当前项目内仍是客服 Skill 文件。
5. PRD 要求的“考试模式”尚未进入 API schema。

## 4. 建议开发顺序

### P0：保证当前主链路可信

1. 修复 PDF 页数异常，为两份真实资料建立页码/引用抽检。
2. 实现引用修复重试，区分“未配置”“Provider 失败”“引用校验失败”。
3. 实现学术诚信 Guard。

已完成：“资料1”“第二份 PDF”及文件名指代会解析为 QueryPlan `document_ids`。

已完成：Web 对话支持资料类型、指定文件和页码范围，引用可展开原始片段并打开 PDF 对应页。

### P1：补齐学习闭环

1. 练习历史、rubric/来源展示、错题重练、重新评估。
2. 对话历史、回答反馈、考试模式、中英双语格式验收。
3. 学习趋势、常见错误、最近练习和用户偏好页。
4. 课程与资料的编辑、删除、重试和安全确认界面。

### P2：达到作品发布标准

1. 补充 PRD 规定的出题和批改离线评测集并产出报告。
2. 增加 request/trace ID、LLM/RAG/Agent 指标、费用与降级监控。
3. 替换旧客服 Skills，接入教学 Skill 与 ToolManager。
4. 清理旧 EchoMind 入口和文档，补齐演示数据、架构图和演示脚本。
