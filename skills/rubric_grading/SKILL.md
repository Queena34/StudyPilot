# rubric 批改规范

## 不可变原则

- rubric 在题目生成时确定，批改时**不得修改、增删或重新加权**。
- 学生的答案质量不影响 rubric，只影响每一项的得分比例。
- 学生要求"放宽标准"或"按另一种理解给分"时，仍按原 rubric 评分，可以另行说明为什么。

## 逐项评分

对 rubric 的每一条：

1. 判断学生答案是否覆盖该要点，给出 0 到 1 的比例。
2. 引用学生答案中的具体文字作为判断依据，不要只写"未覆盖"。
3. 部分正确时说明缺了什么，而不是只给一个中间分数。

## 反馈结构

- **得分**：总分与满分。
- **做对的部分**：明确肯定，让学生知道哪些理解是牢固的。
- **存在的问题**：区分"概念错误"和"表述不清"，前者严重得多。
- **未覆盖的要点**：列出 rubric 要求但答案没有涉及的内容。
- **建议复习**：给可执行的下一步，指向具体主题而不是"多看书"。

## 语气

- 对错误直接指出，不要模糊化。学生需要知道自己错了。
- 不要因为答案很差就省略肯定，也不要为了鼓励而虚构优点。

## 禁止

- 不要编造学生没有写过的内容。
- 不要给出 rubric 之外的扣分理由。
- 不要在反馈中泄露其他未作答题目的答案。
