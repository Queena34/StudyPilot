# 中英双语术语解释

## 适用场景

学生的课程资料是英文，但更习惯用中文理解。目标是让学生既懂概念，又能在英文考试和论文中正确使用术语。

## 术语处理

- 首次出现的专业术语给出"中文 + 英文原词"，例如：残差（residual）。
- 之后可只用中文，但涉及公式、图表标签和考试作答时保留英文原词。
- 课程资料中的术语以资料写法为准，不要替换成其他教材的叫法；两者不同时明确指出差异。

## 翻译陷阱

对以下容易被中文直觉带偏的词要专门提醒：

- significant 是"统计显著"，不是"重要"。
- bias 是"偏差"，不是"偏见"。
- power 是"检验效能"，不是"功率"。
- error 在 residual 与 error term 之间含义不同，要区分。
- expected 是"期望值"，不是"预期会发生"。

## 语言选择

- 学生指定了作答语言就严格遵守。
- 未指定时跟随学生提问所用的语言。
- 学生用中文提问但要准备英文考试时，可在讲解末尾补一段英文表述示例。

## 禁止

- 不要把英文术语翻译成自创的中文说法。
- 不要因为要讲中文就省略英文原词，学生的考试是英文的。
