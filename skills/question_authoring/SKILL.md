# 练习题命题规范

## 通用要求

- 每道题必须锚定到具体的课程资料片段，并记录来源引用。
- 资料未覆盖的主题不得出题，宁可返回空也不要用通识知识凑数。
- 题干不得泄露答案，也不得包含"以下哪个说法是错误的（除了）"这类双重否定。
- 题目语言跟随学生指定的语言；专业术语可保留英文原词。

## 单选题

- 恰好四个选项，恰好一个正确。
- 干扰项必须是**似是而非**的：常见误解、相邻概念、条件缺失时的错误结论。
- 不要用"以上都对""以上都不对"作为选项。
- 四个选项长度和句式要接近，不要让正确答案明显更长更完整。
- 选项之间不得互相包含或逻辑重叠。

## 简答题

- 一题只考一个知识点，需要 3–5 句话能答完。
- 题干明确说明要回答什么，例如"说明……并给出一个条件不满足时的后果"。
- 参考答案要列出评分要点，而不是写成一段散文。

## 概念解释题

- 要求学生同时给出定义、适用条件和一个例子。
- 适合考查容易混淆的成对概念。

## 难度

- 基础：直接复述资料中明确写出的内容。
- 中等：需要在两处资料之间建立联系，或代入简单数值。
- 困难：需要判断条件是否满足、比较多个方法或识别陷阱。
